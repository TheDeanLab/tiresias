## Naming Conventions

**Files:**
- Module names: `lowercase_with_underscores` (e.g., `blind_rl.py`, `test_tiling.py`)
- Python packages: `lowercase` (e.g., `tiresias`)
- Test files: `test_<module>.py` prefix (e.g., `test_blind_rl.py`)

**Functions:**
- Public API: `lowercase_with_underscores`, exposed in `__init__.py::__all__` (e.g., `estimate_blind_psf_cupy`, `generate_theoretical_psf`)
- Private helpers: `_leading_underscore` (e.g., `_normalise_psf`, `_configure_cupy_cache`)
- Type aliases: `PascalCase` (e.g., `Array`, `Convolve` in `blind_rl.py`)

**Variables:**
- Constants: `SCREAMING_SNAKE_CASE` (e.g., `DEFAULT_BLIND_CHUNK_XY`, `BLIND_CHUNK_ALIGNMENT`)
- Parameters: `lowercase_with_underscores` (e.g., `chunk_xy`, `pad_z`, `vram_gb`)
- Loop counters: Short (e.g., `z`, `y`, `x`, `i`, `axis`)

**Types & Classes:**
- Classes: `PascalCase` (e.g., `FftConvolutionEngine`, `BatchedFftConvolutionEngine`)
- Named tuples: `PascalCase`
- Type hints: `Any` for xp (numpy/cupy abstraction), `Array` for flexible array type

## Where to Add New Code

**New Feature (Algorithm):**
- Primary code: `src/tiresias/blind_rl.py` (if core algorithm) or `src/tiresias/tiling.py` (if orchestration)
- Tests: `tests/test_blind_rl.py` or `tests/test_tiling.py`
- Example: New FFT engine variant → add class in `blind_rl.py`, test in `test_blind_rl.py`

**New PSF Mode or Seed Type:**
- Implementation: `src/tiresias/seeds.py` (for generation/loading logic)
- Tests: `tests/test_seeds.py`
- Example: Load PSF from HDF5 → add function `load_psf_seed_hdf5` in `seeds.py`

**New CLI Command:**
- Implementation: `src/tiresias/cli.py` (add argument builder and main function)
- Tests: `tests/test_cli.py` (mock tiling/algorithm layers, verify argument flow)
- Entry point: Add to `pyproject.toml::project.scripts` section

**New Tile Selection Strategy:**
- Implementation: `src/tiresias/tiling.py` (add to selection logic, register in `TILE_SELECTION_STRATEGIES`)
- Tests: `tests/test_tiling.py` (verify ranking, coverage)
- Configuration: Pass `tile_selection_strategy` parameter through CLI and API

**Utilities (Shared Helpers):**
- Shared validation/conversion: `src/tiresias/blind_rl.py` (module-level helpers like `_shape`, `_scalar`)
- Shared formatting/I/O: `src/tiresias/tiling.py` (e.g., `open_tiff_memmap`, `detect_vram_bytes`)
